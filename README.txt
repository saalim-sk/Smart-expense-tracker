EXPENSE TRACKER - STUDENT DEMO

HOW TO RUN
1. Extract expense_tracker_demo.zip.
2. Open the extracted folder.
3. Double-click index.html to open it in Chrome or Edge.
4. Login with username: admin, password: 1234.
5. Add Income or Expense entries to test the dashboard.

FILES
- index.html: Login screen
- dashboard.html: Dashboard and transaction form
- style.css: Styling and responsive layout
- script.js: Calculations, transaction history, search, delete, localStorage

IMPORTANT
This is a front-end classroom demo. Login is demo-only and is not secure production authentication.
Transactions are stored in the current browser's local storage. Clearing browser data may remove them.
